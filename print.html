01Typst概述

概述

Typst是一种用于排版文档的标记语言，可以用于排版各种精美的论文、文章、书籍、报告和作业等。它是LaTex的精神续作，但是运行环境和编译速度都要更简单、更快捷。

它设计了一种脚本结合简单的标记语法实现复杂的排版效果。并且支持模板创建、文件包含等，可以很好的组织大型著作如书籍的排版。学习曲线相比LaTex要小一些。

如果你有一些编程语言或脚本编程的基础，Typst的脚本语法基本可以很容易上手。

为了深入掌握，笔者花费了一定的时间去学习其文档和《小蓝书》中的内容，并结合自己的形式简化和精炼，总结出了该系列的笔记，希望和大家一起学习Typst排版。

使用方式

配置 Typst 运行环境你可以使用官方在线编辑器、VSCode或其他工具，推荐和比较常用的是前两者。
官方在线编辑器需要注册账号使用，可以在线创建和存储项目。
VSCode安装扩展使用。

VSCode提供强大的语法提示和简便的文档预览。

数字

Typst包含两种数字类型，整型integer和浮点型float:

  • 整型integer：代表整数，可以是负数、零或正数。 由于 Typst 使用 64 位来存储整数，整数不能小于 -9223372036854775808 或大于 9223372036854775807。
  • 浮点型float：一个实数的有限精度表示。Typst 使用 64 位来存储浮点数。

字符串

字符串可以看做是由若干字符按顺序组成的字符数组。

所有长度和索引都以 UTF-8 字符为单位。 索引从零开始，负索引会回到字符串的末尾。

string{
    len() -> integer   // 字符串在UTF-8编码字节中的长度
    first() -> any     // 返回字符串中第一个字符
    last() -> any      // 返回字符串中最后一个字符
    at(                // 返回定索引位置的字符
        index：int,           // 索引
        default: any,         // 超出索引范围后返回的默认值
    ) -> any
    slice(             // 截取子字符串
        start:integer,
        end:integer,
        count: integer,
    ) -> string
    clusters() -> array    // 返回单个字符组成的数组
    codepoints() -> array  // 返回单个字符Unicode码组成的数组
    contains(pattern:string/regex) -> boolean  //判断字符串是否包含指定的模式
    starts-with(pattern:string/regex) -> boolean //判断字符串是否以指定的模式开始
    ends-with(pattern:string/regex) -> boolean //判断字符串是否以指定的模式结尾
    find(pattern:string/regex) -> string/none // 在字符串中搜索指定的模式，并以字符串形式返回第一个匹配项，如果没有匹配项，则返回 none。
    position(pattern:string/regex) -> integer/none //在字符串中搜索指定的模式，并返回第一个匹配项的索引，如果没有匹配项则返回 none。
    match(pattern:string/regex) -> dictionary/none //在字符串中搜索指定的模式，并返回一个包含第一个匹配项详细信息的字典，如果没有匹配项则返回 none。
    matches(pattern:string/regex) -> array  在字符串中搜索指定的模式，并返回一个包含所有匹配项详细信息的字典数组
    value.replace(                  // 查找并替换匹配的字符串
        pattern:string/regex,          // 查找的字符串或模式
        replacement:string/function,   // 替换的内容或处理函数
        count: integer,                // 替换指定的前几项
    ) -> string
    trim(    // 从字符串的一侧或两侧移除匹配模式的内容，并返回替换结果
        pattern:string/regex,          // 查找的字符串或模式
        at: alignment,                // 可以使用 start 或 end 来仅修剪字符串的开头或结尾。如果省略，则会修剪字符串的两侧。
        repeat: boolean,              //决定是重复移除模式的匹配项还是只移除一次。默认为 true。
    ) -> string
    split(pattern:string/regex) -> array  // 按字符串或模式进行切分，返回数组
}

其中，match()和matches()方法的字典形式：

(

    text: string  // 匹配的文本
    captures: array // 包含每个匹配的捕获组的字符串。 数组的第一项包含第一个匹配的捕获组，而不是整个匹配！除非 pattern 是带有捕获组的正则表达式，否则此项为空。

datetime的构造

日期时间类型可以使用datetime()函数构造，可以看做是datetime类型的构造函数：

datetime(
    year：         //年份
    month：        //月份
    day：          //日期
    week_number：  //周数
    weekday：      //星期
    hour：         //小时
    minute：       //分钟
    second：       //秒数
)

你可以指定其中的全部或部分。

// 构造日期
#let date = datetime(
  year: 2025,    // 年
  month: 6,      // 月
  day: 1         // 日
)

// 构造时间
#let time = datetime(
  hour: 15,      // 时
  minute: 27,    // 分
  second: 57     // 秒
)

绝对定位place()

place()用于将内容放置在父容器（页面）的指定位置。

place(
    alignment: auto alignment,    // 位置，默认：start
    float: bool,       // 是否浮动布局，默认：false
    clearance: length, // 放置的元素在浮动布局中的间隙量。默认：1.5em
    dx: relative,      // 水平偏移
    dy: relative,      // 垂直偏移
    content,           // 定位的内容
) -> content

设定放置位置

alignment可能的值为：

  • start：在文本方向的开头对齐。

  • end：在文本方向的末尾对齐。

  • left：左对齐。

  • center：水平居中。

  • right：右对齐。

  • top：垂直顶部对齐。

  • horizon：垂直居中对齐。

  • bottom：在底部对齐。

alignment指定相对于父容器中的哪个位置放置内容。

  • 如果 float 是 false，那么可以是除 auto 之外的对齐方式。
  • 如果 float 是 true，那么必须是 auto、top 或 bottom。
#rect(width:100%,height: 200pt)[
  #place(start)[top/start]
  #place(center)[center]
  #place(right)[right/end]
  #place(horizon)[horizon]
  #place(center+horizon)[center+horizon]
  #place(right+horizon)[right(/end)+horizon]
  #place(bottom)[bottom]
  #place(bottom+center)[bottom+center]
  #place(bottom+right)[bottom+right(/end)]
]

  rect(width: 100%, height: 100pt, fill: aqua),

  top + center,

  rect(width: 100%, height: 100pt, fill: aqua),

#lorem(400)

scope的默认值是"column"，如果页面级别设定了分栏，则绝对定位的内容会显示在当前栏内。

值含义
"column"放置到当前列中。
"parent"相对于父元素定位，允许内容跨越所有列。需要启用float。

通过将scope的值设为"parent"，可以实现跨栏效果。

前天（6月26日）编写了一些Tytpst的页面函数，用于方便的创建诸如纯色背景页面、图片背景页面等的基本函数，并希望基于它们创建更复杂的封面和内页排版效果。

函数已经打包为了Typst模块PageLib.typ，具体使用时可以使用如下形式引入，并直接使用其中的函数。

#import "PageLib.typ":*  // 导入页面函数库

完整的模块代码见本文最后。

今天花点时间整理本文，补充了设计思路和具体的函数实现以及使用方法，对部分函数做了改进，希望对使用Typst排版内容的朋友们有点用处。

纯色背景页面函数

自定义函数如下：

#let color_page =  page.with(fill:white)
  • color_page()被定义为内置页面函数page()的变种，设定其填充为纯白色。

使用：

可以直接使用color_page()：

#color_page()[]         // 一个纯白色背景的页面

可以用fill参数设定页面的背景色：

#color_page(fill:blue)[]  // 一个纯蓝色背景的页面

方括号中输入页面的具体内容即可。

说是纯色背景，其实使用渐变或纹理也是可以的。这里以渐变为例：

#color_page(fill:gradient.linear(..color.map.crest))[]

使用with()的好处

  • 使用with()可以创建函数的变体，尤其基于已经存在的页面元素函数，可以更方便的构造函数的变体。
  • 而且类似继承，你可以在新函数中继续使用原函数的所有参数，而不是自己重新写一遍这些参数

使用bg_page()函数取代color_page()

  • 其实color_page()完全可以由bg_page()取代
  • 但是为了介绍with()这种思路还是保留了下来

  bg_content,            // 背景内容

图片背景页面函数

图片背景页面函数pic_page()基于基于背景页面函数bg_page()，专门用于创建页面背景是图片的效果，并且提供对背景图片的变换（定位，旋转、缩放、尺寸等）的控制。

  • pic_page()目前只支持一张背景图。
// 图片背景页面
#let pic_page(
  img_path,              // 图片路径
  fill:white,            // 背景颜色或渐变、纹理
  // ----------- 定位与变换 ----------- 
  pos:(0pt,0pt),         // 左上角位置
  size:(100%,100%),      // 尺寸
  angle:0deg,            // 旋转角度
  scales:(100%,100%),    // 缩放
  // ---------------------- 
  body                   // 页面正文
) =  bg_page(fill:fill,)[
      #place(top,dx:pos.at(0),dy:pos.at(1))[
        #rotate(angle)[
          #scale(x:scales.at(0),y:scales.at(1))[
            #image(img_path,width:size.at(0),height: size.at(1))
          ]
        ]
      ]
    ][#body]

基础使用

默认背景图会自适应整个页面尺寸。

#pic_page("me.jpg")[这里是正文]

控制背景图片的位置和尺寸

可以通过pos和size参数方便的控制背景图的尺寸和位置。

#pic_page("me.jpg",size: (100%,50%))[这里是正文]



#pic_page("me.jpg",size: (100%-2cm,30%),pos:(1cm,1cm))[这里是正文]

旋转也不在话下：

#pic_page("me.jpg",size: (100%-2cm,30%),pos:(1cm,2cm),angle: -4deg)[这里是正文]

绝对定位内容函数

绝对定位内容函数，是对内置的定位函数place()、旋转函数rotate()以及缩放函数scale()的整体封装，实现对任意内容在当前页面中的绝对定位和变换。

// 绝对定位的内容
#let place_content(
  pos:(0pt,0pt),       // 左上角位置
  size:(auto,auto),    // 尺寸
  angle:0deg,          // 旋转角度
  scales:(100%,100%),  // 缩放
  body                 // 具体内容
) = [
  #place(top,dx:pos.at(0),dy:pos.at(1))[
    #rotate(angle)[#scale(x:scales.at(0),y:scales.at(1))[
        #body
      ]
    ]
  ]
]

#let rect_page(

  shadow_offset:(5pt,5pt),     // 阴影偏移
  shadow_fill:luma(200),     // 阴影填充
  // ----------- 副矩形设置 -----------
  show_bg_rects:false,         // 是否显示副矩形
  bg_rects_count:1,            // 副矩形数量
  bg_rects_deg:2deg,           // 副矩形旋转角度
  bg_rects_start_deg:-4deg,           // 副矩形旋转角度
  bg_rects_fill:luma(200),   // 副矩形基础色
  // ----------- 其他自定义背景内容 -----------
  bg_contents:none,                 // 其他自定义背景内容
  // ---------------------- 
  body                         // 页面正文
) = bg_page(fill: bg_fill)[
  #let p = 100% - margin * 2  // 版心宽度和高度
  #let top_left = (margin+ shadow_offset.at(0),margin+ shadow_offset.at(1))
  // 版心副矩形
  #if show_bg_rects [
    #has_shadow = false  // 强制关闭阴影
    #for i in range(bg_rects_count) {
      let opt = eval("-" + str(i / bg_rects_count * 100) + "%")
      let ang = bg_rects_start_deg + bg_rects_deg * i
      place_content(pos:(margin,margin),angle:ang)[
        #rect(fill:bg_rects_fill.opacify(opt),width: p,height: p,radius: radius)
      ]
    } 
  ]
  // 其他自定义背景内容
  #if bg_contents != none [#bg_contents] 
  // 版心阴影
  #if has_shadow and show_bg_rects == false [
    #place_content(pos:top_left)[
      #rect(fill:shadow_fill,width: p,height: p,radius: radius)
    ]
  ]
  // 版心
  #place_content(pos:(margin,margin))[
    #rect(fill:fill,width: p,height: p, inset: inset,radius: radius)
  ]
][#body]

【Typst第三方包】Latex公式转Typst：MiTex

概述

LaTeX 对 Typst 的支持，由 Rust 和 WASM 提供支持。

MiTeX 将 LaTeX 代码处理成抽象语法树 （AST）。然后，它将 AST 转换为 Typst 代码，并通过 eval 函数将代码评估为 Typst 内容。

MiTeX 已被证明在大型项目中是实用的。它已经从 OI Wiki 正确转换了 32.5k 方程。相比 texmath，MiTeX 在该 wiki 项目中具有更好的显示效果和性能。它也更容易使用，因为将 MiTeX 导入 Typst 只是一行代码，而 texmath 是一个外部程序。

此外，MiTeX 不仅体积小 ，而且速度快 ！MiTeX 的大小仅为 185 KB 左右，而 texmath 的大小为 17 MB。下面显示了一个不严格但直观的比较。从 OI Wiki 转换 32.5k 方程，texmath 大约需要 109 秒，而 MiTeX WASM 只需要 2.28 秒，MiTeX x86 只需要 0.085 秒。

多亏了 @Myriad-Dreamin，他完成了最复杂的开发工作：开发用于生成 AST 的解析器。

MiTeX 作为 Typst 封装

  • 使用 mitex-convert 将 LaTeX 代码转换为字符串中的 Typst 代码。
  • 使用 mi 在 Typst 中渲染内联 LaTeX 方程。
  • 使用 mitex(numbering: none, supplement: auto, ..) 或 mimath 在 Typst 中渲染块 LaTeX 方程。
  • 使用 mitext 在 Typst 中渲染 LaTeX 文本。

PS： #set math.equation(numbering: "(1)") 也适用于 MiTeX。

【Typst】绘图包CeTZ

简介

该包提供了一种使用类似于Processing的API绘制画布的方法，但使用TikZ的相对坐标和锚。您也不必担心意外地在其他内容上绘制，因为画布将自动调整大小。记住：向上是积极的！

名称CeTZ是“CeTZ，ein Typst Zeichenpaket”（德语意为“CeTZ，一个Typst绘图包”）的递归首字母缩写。

使用

#import "@preview/cetz:0.3.0"

#cetz.canvas({
  import cetz.draw: *
  // 绘图代码
})

请注意，绘制函数是在canvas块的范围内导入的。建议这样做，因为CeTZ的一些绘图函数可能会覆盖Typst的函数，例如line。

画布canvas()

设置用于绘图的画布。

参数

canvas(
    length: length ratio ,    // 指定单位坐标的实际长度，默认: 1cm
    debug: bool ,             // 是否调试模式，调试模式下显示每个元素的边界框，默认: false
    background: none color ,  // 画布背景颜色，默认: none
    body: none array element  // 画布内容
) -> content

element，一种代码块，其中调用了draw.typ中的函数。

#cetz.canvas(
  length: 4cm,  // 单位长度
  debug: true,  // debug
  {
  import cetz.draw: *
  // 绘图代码
  circle((0,0))  // 绘制单位圆
})



circle((0,0))      // 绘制单位圆
line((0,0),(1,1))  // 绘制线段

可以看出，cetz的画布canvas：

  • 采用原点(0,0)，水平向右为x轴正方向，垂直向上为y轴正方向的坐标系。
  • 使用单位长度，而不是带单位（比如mm、cm、pt等）具体长度值，而单位长度length可以设为任意具体长度（默认1cm）
  • 画布会根据绘制内容自动调整大小，只显示绘制了内容的最小区域

使用前一坐标连续绘制

使用()将采取上一绘制元素的终点坐标，从而实现连续绘制效果：

line((0,0), (1, 1))
line((),(1,2))          // 起点为上一线段终点
circle((),radius: 0.1)  // 圆心为上一线段终点

如果没有上一终点，则()默认为(0,0)。

相对前一坐标绘制

circle((0, 0), stroke: blue)
circle((rel: (1, 0)), stroke: red)  // 相对于上一图元终点或锚定点的相对坐标绘制

换成线段后可以看到确实是基于line的终点：

line((),(1,0))
circle((rel: (1, 0)), stroke: red) // 相对于上一图元终点或锚定点的相对坐标绘制



line((),(1,0),name: "l1")
circle((rel: (1, 0),to:"l1.mid"), stroke: red) // 以l1中点作为原点，偏移(1, 0)位置画圆

样式设置

cetz的图元样式主要涉及填充和描边，并且设定方式十分灵活：

// 方法1：直接在绘制的图元中以参数形式设定
circle((0,0),fill:red,stroke:none)

// 方法2：在绘制前使用fill()或stroke()函数设定
fill(red)
stroke(none)
circle((0,0))

// 方法3：在绘制前使用set-style()函数设定
set-style(stroke: blue, fill: red)
circle((0,0))

其中：

  • fill()、stroke()和set-style()函数的样式设定可以认为是在画布中全局的设定，图元内部的参数形式设定可以认为是局部设定
  • 全局设定直到遇到下一次全局修改才会变化，而局部设定可以局部覆盖全局设定的样式。

stroke的细节设定与Typst中一致：

stroke(
  paint: auto color gradient pattern,  // 描边颜色
  thickness: auto length,              // 描边粗细
  cap: auto str,                       // 描边末端的渲染方式
  join: auto str,                      // 拐角渲染方式
  dash: none auto str array dictionary,  // 虚线样式
  miter-limit: auto float,               // 
) -> stroke

你也可以设定渐变填充和虚线边线等：

stroke(
      (
        paint:blue,
        thickness:2pt,
        dash:"dashed"
      )
    )
  fill(gradient.linear(..color.map.crest))
  circle((0,0))

圆circle(）

circle(
    position: coordinate ,  // 圆心位置
    radius: number array    // 半径，默认：1，(x,y)形式指定椭圆半径
    name: none string ,     // 名称
    anchor: none string ,   // 锚点,默认“center”

  • fill和stroke基本上是所有图元都有的样式。
  • anchor是CeTZ内部独特的相对定位方式“锚点”，name用来命名图元，并辅助“锚点”定位。

锚定位anchor

anchor用于定位相对于图元的位置，有两种用法：

  • 方法1：给上一图元指定anchor参数，然后相对上一图元的锚定位置进行下一图元的绘制
  • 方法2：给上一图元指定name参数，然后在后续绘制图元上指定具名图元的anchor后在指定锚定位置进行绘制
// anchor的第一种用法
circle((0,0), anchor: "west")  // 绘制单位圆，设定锚定位置在“西”

fill(red)
stroke(none)
circle((0,0), radius: 0.1)     // 以上一图元的锚定位置为原点绘制半径为0.1单位长度的圆

等价的第二种形式：

circle((0,0), name: "c1")  // 绘制单位圆，命名为“c1”

fill(red)
stroke(none)
circle("c1.west", radius: 0.1)  // 以名为“c1”的图元的“西”锚定位置为原点绘制半径为0.1单位长度的圆

圆弧arc()

arc(
    position: coordinate , // 圆心位置
    start: auto angle ,    // 弧线起始的角度
    stop: auto angle ,     // 弧线结束的角度
    delta: auto angle ,    // 增量角度
    name: none string ,
    anchor: none string ,
    radius: number or array，  // 半径，(xr,yr)形式可建立椭圆弧
    mode: string,        // 绘制模式："OPEN"、"CLOSE"、"PIE"
    update-position: bool // 是否将当前画布位置更新至圆弧终点（锚点"arc-end"）。默认: true
)

绘制模式

  • “OPEN”模式：不绘制额外线条，仅显示弧线；
  • “CLOSE”模式：会从弧线起点到终点绘制一条线，形成弓形；
  • “PIE”模式：则从弧线起点和终点分别向原点绘制线条，形成扇形。
arc((0,0), start: 45deg, stop: 135deg)
arc((0,-0.5), start: 45deg, delta: 90deg, mode: "CLOSE")
arc((0,-1), stop: 135deg, delta: 90deg, mode: "PIE")

请注意，三个角度参数（start、stop和delta）中必须设置其中两个。当前位置()将更新为圆弧终点坐标（锚点<font style="color:rgb(0,0,0);">arc-end</font>）。

锚点

支持边界和路径锚点。

  • arc-start 弧线曲线起始位置（默认值）。
  • arc-end 弧线曲线结束位置。
  • arc-center 弧线曲线中点位置。
  • center 弧线中心点（该位置随弧线闭合状态变化）。
  • chord-center 起止点间弦线中心位置。
  • origin 弧线所属圆的圆心。

贝塞尔曲线

bezier(
    start:coordinate ,  // 起点坐标
    end: coordinate ,   // 终点坐标
    ctl1: coordinate ,   // 起始控制点
    ctl2: coordinate ,   // 结束控制点
    ..style: style ,
    name: none string
)

前两个位置参数被视为三次贝塞尔曲线的控制点，其中第一个是起始控制点，第二个是终止控制点。若提供单个控制点则可绘制二次贝塞尔曲线。命名参数用于样式设定。

绘制二次贝塞尔曲线

// 背景网格
grid((0,0), (2,-2),name: "g",help-lines:true)

// 设定顶点和控制点
// 前两个坐标分别是起点和终点
// 第三个坐标是控制点，设定三个坐标就是二次贝塞尔曲线
let (a,b,c) = ((0,0),(2,0),(1,1)) 


// 绘制顶点和控制点连线
line(a,c,b,stroke:(paint:orange,dash:"dashed"))

// 绘制二次贝塞尔
bezier(a,b,c)

// 绘制顶点
set-style(
circle:(fill:white,stroke:1pt+red)
)
circle(a,radius: .05)
circle(b,radius: .05)
circle(c,radius: .05)

// 绘制文本
content((a,0.1,(0,-1)),[a])
content((b,0.15,(rel:(0,-1))),[b])
content((c,0.2,(rel:(0,1))),[c])

将多个元素组合为一个群组。该元素作为作用域存在，所有状态变更（如变换与样式调整）仅作用于群组内元素。群组外的元素不会受到群组内部变更的影响。

    body: elements function ,  // 群组内的元素
    name: none string ,
    anchor: none string ,
    padding: none number array dictionary， // 内边距
    ..style: style
)
  • padding：在组边界框周围添加多少内边距。none表示不添加内边距。数字表示所有边均等添加内边距。数组遵循类似CSS的内边距格式：(y, x)、(top, x, bottom) 或 (top, right, bottom, left)。

组内命名元素也可作为字符串锚点访问，具体参见第4.6节。

坐标系

坐标是绘制图像的画布上的位置。它们以字典形式呈现，以下小节将定义每个系统的键值对。某些系统采用更隐式的数值数组形式，CeTZ会尝试根据元素类型推断所属系统。

切线

该系统可计算与图形相切的点。具体而言，给定一个几何元素和某点，从该点引出一条直线使其“接触“该元素（更规范地说，与该元素相切）。直线与图形的接触点即为该坐标系所指向的位置。

(
    element:str,        // 切线点所在元素
    point:coordinate,   // 切线经过点的点
    solution:int        // 多个解时选择第几个解
)

计算给定形状的切线需要特殊算法。当前算法通过假设中心锚点与顶部锚点之间的距离（参见第2.2节）作为圆的半径来实现这一计算。

// 绘制圆c1和点c2
    circle((),name: "c1")
    circle((2,2),radius: .1,name: "c2",fill:black)
    
    // 求切线点
    set-style(fill:orange)
    let t1 = (element:"c1",point:"c2",solution:1)
    let t2 = (element:"c1",point:"c2",solution:2)

    // 绘制切线
    set-style(
        line:(
            stroke:(dash:"dashed")
        )
    )
    line("c2",t1)
    line("c2",t2)

    // 绘制切点
    // c1和c2的切线点1
    circle(t1,radius: .1)
    // c1和c2的切线点2
    circle(t2,radius: .1)

    // 绘制文本
    content("c1",[c1])
    content((2.5,2),[c2])

插值法

用于在给定距离值的情况下，对坐标a和b进行线性插值。若该值为数值，则位置将位于从a指向b的绝对距离处；亦可提供比例值作为a与b之间的相对距离。
